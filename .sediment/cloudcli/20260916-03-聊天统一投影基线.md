## 背景
- session-sediment:cloudcli
- 将多个 harness 的不同事件语义投影为稳定、一致的聊天交互模型。

## 进展
- [x] 建立 provider-agnostic Turn / Segment / Lifecycle 投影。
- [x] 支持完整 Turn 与左截断 partial Turn。
- [x] 明确 answer、reasoning、tool、progress、summary、error 类型。
- [x] 明确 active、complete、attention 生命周期。
- [x] ExecutionProcess 改为消费统一投影。
- [x] 多段 Answer 始终可见，Reasoning 不再受双重折叠控制。
- [x] Reasoning disclosure 使用稳定 segmentId。
- [x] 流式、finalize、持久化刷新保持 DOM 与 disclosure 身份。
- [x] 82 个测试文件、593 个测试通过；类型检查和构建通过。
- [ ] 服务端完整 Turn 分页、snapshot、seek 尚未实现。
- [ ] 长列表真正窗口化和动态高度校准尚未实现。

## 决策与理由
- Provider adapter 只提供事实，展示层统一投影 Turn/Segment。
- Answer 永不进入过程折叠；只有 complete Process Segment 可折叠。
- active 与 attention 保持可见，用户 disclosure ownership 优先。
- WorkBuddy 作为交互参考，不复制其私有事件模型。

## 踩坑 / 注意点
- 时间戳不能作为稳定 disclosure 身份；hydration 可能改写格式或精度。
- 工具视觉分组和语义折叠不是同一边界，后续不可混为一个模型。
- 现有 100px 未测量占位仍会造成长会话空白，留待窗口化阶段解决。
