# [cloudcli] 执行过程标题吸顶收起

- id: 20260917-05

- status: 已完成，待真机验证

## 背景
- 长执行过程（如“执行过程 · 17 次工具调用”）展开后，标题会滚出视口，移动端难以回到起点收起。

## 进展
- [x] 执行过程末端以独立标记限定吸顶边界，成员行保持原有 DOM 层级。
- [x] 展开标题加入 `sticky top-0 z-10`、半透明背景和模糊。
- [x] 新增展开/收起态的样式契约测试。
- [x] 相关 12 个测试、前端类型检查、客户端构建、diff 检查通过。
- [ ] 用真实移动端长任务验证吸顶位置、收起点击及阶段边界。

## 决策与理由
- 仅置顶“执行过程 · N 次工具调用”标题，不置顶用户消息或单个工具卡片。
- 吸顶仅在所属执行阶段内生效，下一条消息出现时自然顶走，避免覆盖后续内容。
- 点击标题沿用既有行为收起整个执行阶段；收起态不吸顶。

## 踩坑 / 注意点
- 不能只给标题加 sticky：它会跨整个聊天列表悬浮并遮住后续消息；末端标记到达聊天面板顶端时必须取消吸顶。
- 不能按动态过程成员重包裹消息行：临时正文被后续工具调用吸收时会触发 React 重挂，丢失懒加载测量、搜索锚点和滚动稳定性。
- 本次未提交、未部署；工作区另有快捷回复等 WIP，未触碰。
- 客户端 lint/build 的非阻断警告为仓库已有问题，未由本次引入。
