## 背景

- 用户要求新建会话仅显示实际已安装的 harness，未安装 OpenCode 不显示。

## 进展

- [x] 增加 `GET /api/providers/available`，聚合检测本机已安装 harness。
- [x] 新建会话选择器按接口结果过滤 provider；已安装但未登录仍显示。
- [x] 页面内缓存与并发请求复用已实现。
- [x] 定位过一次显示错误：运行的是旧 `dist-server`，旧服务缺少新接口，前端兜底展示了全部 provider。
- [x] 确认本机无 `opencode` 命令。
- [x] 路由精确测试、类型检查、客户端构建曾通过。
- [x] 已开始实现体验优化：浏览器 24 小时持久化缓存、Chat 初始化预取、服务端 10 分钟缓存。
- [ ] 体验优化后的完整测试、构建及服务重启命令被用户消息中断，尚未确认部署状态。

## 关键决策

- c: 使用“本地旧值立即展示 + 后台校验更新 + 服务端短 TTL”避免重新打开浏览器时的约 1 秒等待。
- c: 认证状态不参与过滤，避免已安装但尚未登录的 harness 消失。
