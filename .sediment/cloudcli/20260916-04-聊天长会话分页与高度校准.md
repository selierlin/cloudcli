- 延续统一 Turn / Segment 投影，解决长会话分页、空白占位和滚动跳动。

- [x] 客户端初次加载与向上翻页接入 Turn 分页。

- [x] 未测量行按文本长度、消息类型和工具组状态估高。
- [x] 会话切换时清理高度缓存，避免跨会话串高。

## 决策与理由
- 数据分页与视口懒加载保持分层，不引入第三方虚拟列表。
- 已测量高度归观察器缓存所有，不归临时 React 组件实例所有。
- Routine 多工具组按折叠摘要估高；单工具和异常组按展开状态估高。
- 100px 只保留为没有调用方估值时的兜底。

## 踩坑 / 注意点
- Provider 每次读取可能重建消息 id，snapshot hash 不能依赖易变 transport id。
- 固定 100px 占位会让长文本进入视口时产生明显空白和滚动修正。
- 行组件卸载后仅保存本地 state 不够，重新挂载仍会退回估值。
- 完整虚拟化会破坏现有 DOM 搜索、滚动锚点和跨消息选择语义。
